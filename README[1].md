# P. Vijai Krishnan Personal Website

This is a static HTML/CSS website designed for GitHub Pages.

## Files
- `index.html` contains the website content.
- `style.css` contains the visual design.

## Publish on GitHub Pages
1. Create a GitHub repository named `yourusername.github.io`.
2. Upload `index.html` and `style.css`.
3. Commit the files to the default branch.
4. In the repository, open Settings > Pages.
5. Select the deployment source for the default branch and save.
6. Visit `https://yourusername.github.io`.

Before publishing, replace the LinkedIn URL if needed and review all claims and contact details.
